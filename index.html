Named for the fire that ended a tyranny.

Muhanad Amer is an Iraq-based cybersecurity enthusiast with a hands-on pull toward CTF challenges, web security, and penetration testing — the kind of work where you learn how a system breaks before you can trust how it holds.

That curiosity runs alongside a builder's instinct: writing Python tooling, managing data with MySQL, living day-to-day in Linux, and applying artificial intelligence and prompt engineering to make security work smarter, not just harder.

The goal is straightforward and still in motion: build a professional career in cybersecurity — one lab, one exploit, one clean line of code at a time.
